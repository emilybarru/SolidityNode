# SolidityNode

SolidityNode is a Real-Time Execution Engine for decentralized Smart Contract Processing and Dynamic Data Hub management.

SolidityNode is built to be simple and practical, focusing on doing one thing well.

**Why SolidityNode?**

- SolidityNode is a Real-Time Execution
- Engine for decentralized Smart Contract
- Processing and Dynamic Data Hub

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityNode.git`
2. `cd SolidityNode`
3. Install in editable mode: `pip install -e .`

## Configuration

SolidityNode is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
